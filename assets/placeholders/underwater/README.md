# Underwater Placeholder Textures

These 64x64 textures were generated for RedotCraft's underwater biome pass:
coral substrate, seagrass, kelp, coral fan, coral branch, sponge, and anemone.
They are project placeholders, not copies of the ZigCraft set, and can be
replaced freely without touching upstream licensing. Run
`tools/gen_underwater_textures.gd` to regenerate them deterministically
(`redot --headless --path . --script res://tools/gen_underwater_textures.gd`).
