# ZigCraft Placeholder Textures

This directory contains an unmodified copy of the development placeholder
textures from [OpenStaticFish/ZigCraft](https://github.com/OpenStaticFish/ZigCraft),
`dev` branch, under `assets/textures/default/`.

The textures used by RedotCraft's current grass, dirt, stone, wood, and leaves
blocks are connected to gameplay. The remaining files are placeholder assets
for future block types and are not hooked up yet.

`water.gdshader` is a Godot-compatible port of ZigCraft's animated water
shader approach from `assets/shaders/vulkan/water.frag`.

The upstream asset README states that some placeholder textures originate from
external Minecraft-compatible resource packs, including Classic Faithful 64x
Jappa, and that ZigCraft does not claim ownership of those third-party assets.
Verify the applicable upstream terms before public redistribution.
