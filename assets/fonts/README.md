# UI fonts

Subsetted copies of [Iosevka](https://typeof.net/Iosevka/) v33.3.4 (SIL Open Font License 1.1;
see `OFL.txt` — copyright (c) 2017-2025 Renzhi Li aka "belkaew").
The full upstream font ships as `Iosevka-<Weight>.ttf` / `Iosevka-Extended<Weight>.ttf`.

These copies were subsetted with pyftsubset (Basic Latin, Latin-1 Supplement,
Latin Extended-A, general punctuation, minus sign) and keep only the
kern/liga/calt/ccmp/locl layout features. They are otherwise unmodified.

Files:

- `iosevka-regular.ttf` — body text
- `iosevka-semi-bold.ttf` — controls, labels, values
- `iosevka-extra-bold.ttf` — panel titles, HUD emphasis
- `iosevka-extended-extra-bold.ttf` — main-menu wordmark
